# برنامه دیاگ ELM327 برای اندروید – نسخه 1.0

## امکانات فعلی
- اتصال Bluetooth Classic از نوع SPP به آداپتورهای ELM327 جفت‌شده (Paired)
- راه‌اندازی اولیه ELM با ATZ، ATE0، ATL0، ATS0، ATH0 و ATSP0
- خواندن کدهای خطای ذخیره‌شده با Mode 03
- خواندن خطاهای Pending با Mode 07
- پاک‌کردن خطاها با Mode 04
- درخواست چند داده زنده: RPM، سرعت، دمای آب، MAP، دریچه گاز، بار موتور و ولتاژ ECU

## ساخت APK
1. پوشه را در Android Studio باز کن.
2. اجازه بده Gradle فایل‌های موردنیاز را دریافت کند.
3. گوشی را با USB وصل کن و Run بزن؛ یا از Build > Build APK(s) استفاده کن.

## اتصال
1. آداپتور ELM327 را به سوکت OBD خودرو وصل کن.
2. سوئیچ را روی ON قرار بده.
3. از تنظیمات بلوتوث Android دستگاه را Pair کن (رمز رایج بعضی مدل‌ها 1234 یا 0000 است؛ به دفترچه آداپتور رجوع کن).
4. در برنامه «نمایش دستگاه‌ها» را بزن و ELM/OBD را انتخاب کن.

## محدودیت‌ها و نکات ایمنی
- این نسخه فقط OBD-II استاندارد را پیاده‌سازی می‌کند؛ خطاهای اختصاصی سازنده، ABS، ایربگ، گیربکس و کدنویسی/فلش ECU را پوشش نمی‌دهد.
- سازگاری به ECU، پروتکل خودرو و کیفیت آداپتور بستگی دارد. کوییک ممکن است برای همه پارامترها/خطاها پاسخ استاندارد ندهد.
- قبل از زدن «پاک کردن خطاها»، کدها را ثبت کن. پاک‌سازی ممکن است Freeze Frame و مانیتورهای آمادگی آلایندگی را پاک کند.
- این پروژه فایل APK آماده نیست؛ سورس پروژه Android Studio است و برای ساخت APK باید با Android Studio کامپایل شود.
- برای استفاده از Android 12 به بالا، مجوز Nearby devices / Bluetooth را تأیید کن.
